# astrbot_plugin_keyword_reply（关键词自动回复）

在 AstrBot WebUI 中配置「关键词 → 回复内容」，当消息中包含关键词（支持句子中间匹配）时自动回复。

## 功能特性

- **WebUI 可视化配置**：所有设置在插件配置页完成，无需改代码
- **子串匹配**：关键词出现在句子中间也算命中（如关键词 `帮助` 可命中 `请问怎么帮助我`）
- **多关键词**：一条规则可配多个关键词（每行一个），命中任意一个即触发
- **多行回复**：单条回复内部可以任意换行
- **多条回复**：用单独一行 `---` 分隔多条回复，每条作为一条独立消息依次发送
- **不干扰正常对话**：只有命中关键词时插件才会介入；未命中时完全不参与，机器人正常的 @ 唤醒 / LLM 对话不受影响
- **命中即阻断 LLM**：关键词命中并成功回复后阻断事件传播，避免 LLM 对同一条消息再回复一次（省 LLM 调用）
- **防风控间隔**：多条回复之间可配置发送间隔（默认 0.5 秒）

## 安装

### 方式一：WebUI 上传（推荐）

1. 打开 AstrBot WebUI → 插件管理 → 安装插件
2. 选择"上传压缩包"，上传 `astrbot_plugin_keyword_reply.zip`
3. 安装后在插件列表启用本插件

### 方式二：手动解压

```bash
# 进入 astrbot 的插件目录（按你的实际部署路径调整）
cd /path/to/AstrBot/data/plugins/
unzip /path/to/astrbot_plugin_keyword_reply.zip
# 重启 AstrBot 或在 WebUI 插件页重载
```

## 配置说明

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| 是否启用 | bool | `true` | 总开关，关闭后插件完全不介入 |
| 区分大小写 | bool | `false` | 关闭时英文关键词不区分大小写；中文不受影响 |
| 发送间隔（秒） | float | `0.5` | 多条回复之间的等待时间，防平台风控；`0` 为不等待，范围 0-60 |
| 关键词回复规则 | 规则列表 | 空 | 每条规则包含：备注 / 关键词 / 回复内容 |

### 规则字段

| 字段 | 说明 |
|---|---|
| 备注 | 仅用于列表区分，不影响匹配 |
| 关键词 | 每行一个，命中任意一个即触发 |
| 回复内容 | 支持多行；用单独一行 `---` 分隔多条回复 |

### 配置示例

**例 1：多关键词 → 单条多行回复**

关键词：
```
帮助
菜单
help
```

回复内容：
```
本机器人支持以下功能：
1. 日常问答（@我 即可）
2. 关键词自动回复
```

**例 2：单关键词 → 多条回复（多个多行一起发送）**

关键词：
```
新人报到
```

回复内容：
```
欢迎新人！
---
进群请先看群公告
---
有问题可以在群里提问
```

命中后将依次发送 3 条独立消息（每条间隔默认 0.5 秒）：
1. `欢迎新人！`
2. `进群请先看群公告`
3. `有问题可以在群里提问`

## 工作原理

1. 插件通过**自定义过滤器**在唤醒检查阶段判断消息是否命中任意规则的关键词：
   - 未命中 → 插件不唤醒、不参与，机器人按原有 @ 唤醒 / LLM 流程工作；
   - 命中 → 插件唤醒并处理该消息。
2. 命中后按规则配置顺序，把所有命中规则的回复逐条通过 `event.send()` 发出；
3. 至少成功发出一条后调用 `event.stop_event()` 阻断事件传播，避免 LLM 重复回复。

## 已验证环境

- AstrBot v4.14.6（pip 发布版）
- 平台适配器：aiocqhttp（OneBot v11，含 napcatQQ）
- Python 3.11

**版本要求**：AstrBot ≥ v4.10.4（依赖 WebUI 的 `template_list` 配置类型；旧版加载时会在日志中明确报"不受支持的配置类型"）。`author` 为 astrbot 必填元数据字段，如需修改请编辑 `metadata.yaml`。

## 已知限制

- 多条回复用单独一行 `---` 分隔，若回复正文某行恰好等于 `---` 会被误认为分隔符（可修改 `main.py` 顶部的 `REPLY_SEPARATOR` 常量）；
- 同一条消息命中多条规则时，会按规则顺序把所有命中规则的回复**全部**发出；
- 规则的关键词或回复内容为空时，该规则自动失效（不会触发、不报错）；
- 回复内容仅支持纯文本（不支持图片 / @ 等富文本组件）。
