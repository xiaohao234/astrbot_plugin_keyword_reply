# astrbot_plugin_keyword_reply（关键词自动回复）

在 AstrBot WebUI 中配置「关键词 → 回复内容」，当消息中包含关键词（支持句子中间匹配）时自动回复。

## 功能特性

- **WebUI 可视化配置**：所有设置在插件配置页完成，无需改代码
- **子串匹配**：关键词出现在句子中间也算命中（如关键词 `帮助` 可命中 `请问怎么帮助我`）
- **整词匹配（可选）**：开启后含英文/数字的关键词必须独立出现才触发——关键词 `mj` 不再命中 `mmj`、`mja2`；`这是mj`、`mj吧` 等中英混排场景不受影响，中文关键词保持句子中间匹配
- **多关键词**：一条规则可配多个关键词（每行一个），命中任意一个即触发
- **多行回复**：单条回复内部可以任意换行
- **多条回复**：用单独一行 `---` 分隔多条回复，每条作为一条独立消息依次发送
- **图片发送（图文混排）**：行首写 `[图片]`（或 `[img]`）加图片链接 / 本地路径即可发图；文字与图片行可任意混排，自由控制图片位置（如：文本消息 → 图片 → 文本消息）
- **WebUI 上传图片池**：在规则的「图片池」字段直接上传图片（支持 GIF 动图），回复内容中用 `[图片:1]` 或 `[图片:文件名]` 引用，精确控制每张图的发送时机；同一图片池可被多条规则复用
- **不干扰正常对话**：只有命中关键词时插件才会介入；未命中时完全不参与，机器人正常的 @ 唤醒 / LLM 对话不受影响
- **命中即阻断 LLM**：关键词命中并成功回复后阻断事件传播，避免 LLM 对同一条消息再回复一次（省 LLM 调用）
- **防风控间隔**：多条回复之间可配置发送间隔（默认 0.5 秒）

## 安装

### 方式一：WebUI 上传（推荐）

1. 打开 AstrBot WebUI → 插件管理 → 安装插件
2. 选择"上传压缩包"，上传 `astrbot_plugin_keyword_reply.zip`
3. 安装后在插件列表启用本插件

### 方式二：手动解压

```bash
# 进入 astrbot 的插件目录（按你的实际部署路径调整）
cd /path/to/AstrBot/data/plugins/
unzip /path/to/astrbot_plugin_keyword_reply.zip
# 重启 AstrBot 或在 WebUI 插件页重载
```

## 配置说明

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| 是否启用 | bool | `true` | 总开关，关闭后插件完全不介入 |
| 区分大小写 | bool | `false` | 关闭时英文关键词不区分大小写；中文不受影响 |
| 整词匹配 | bool | `false` | 开启后英文/数字关键词必须独立出现（前后不能紧贴其他英文字母、数字、下划线）才触发，防止 `mj` 误命中 `mmj` 这类粘连；中文关键词不受影响 |
| 发送间隔（秒） | float | `0.5` | 多条回复之间的等待时间，防平台风控；`0` 为不等待，范围 0-60 |
| 关键词回复规则 | 规则列表 | 空 | 每条规则包含：备注 / 关键词 / 回复内容 |

### 规则字段

| 字段 | 说明 |
|---|---|
| 备注 | 仅用于列表区分，不影响匹配 |
| 关键词 | 每行一个，命中任意一个即触发 |
| 回复内容 | 支持多行；用单独一行 `---` 分隔多条回复；行首写 `[图片]` + 图片来源可发送图片 |
| 图片池 | 可选；在 WebUI 上传图片（支持 GIF 动图），供回复内容中 `[图片:编号]` / `[图片:文件名]` 引用 |

### 配置示例

**例 1：多关键词 → 单条多行回复**

关键词：
```
帮助
菜单
help
```

回复内容：
```
本机器人支持以下功能：
1. 日常问答（@我 即可）
2. 关键词自动回复
```

**例 2：单关键词 → 多条回复（多个多行一起发送）**

关键词：
```
新人报到
```

回复内容：
```
欢迎新人！
---
进群请先看群公告
---
有问题可以在群里提问
```

命中后将依次发送 3 条独立消息（每条间隔默认 0.5 秒）：
1. `欢迎新人！`
2. `进群请先看群公告`
3. `有问题可以在群里提问`

**例 3：图文混排（文本 → 图片 → 文本）**

关键词：
```
公告
```

回复内容：
```
今天的更新公告来啦
---
[图片] https://example.com/update.jpg
---
详情见上图，有问题随时群里问
```

命中后将依次发送 3 条消息：一条文本公告 → 一张图片 → 一条补充说明。`[图片]` 后面也可以写本地路径（如 `/data/bot/images/update.jpg`），要求 AstrBot 进程可访问该文件。

图片也可以和文字放进**同一条消息**（同一块内混合书写），例如：

```
使用说明如下：
[图片] https://example.com/help.jpg
```

这样会作为一条消息发出，文字在上、图片在下。

**例 4：WebUI 上传图片 + 按时机引用**

1. 在规则编辑页的「**图片池**」字段点击上传图片（比如依次上传 `欢迎图.gif` 和 `群规图.png`）；
2. 在回复内容里用 `[图片:编号]`（按上传列表顺序，从 1 开始）或 `[图片:文件名]` 引用：

```
欢迎加入本群！
---
[图片:1]
---
先看一遍群规哦
---
[图片:群规图.png]
---
以上，祝玩得开心
```

命中后将依次发送 5 条消息：文本 → 欢迎图.gif → 文本 → 群规图.png → 文本，每张图出现在哪个位置完全由你在回复内容里的书写顺序决定。

`[图片]` 后面跟的来源支持三种写法：
- **网络图片**：`[图片] https://example.com/a.jpg`
- **本地路径**：`[图片] /data/bot/images/a.jpg`（相对路径按插件数据目录解析）
- **图片池引用**：`[图片:1]` / `[图片:欢迎.gif]`（引用本规则「图片池」上传的图片）

## 工作原理

1. 插件通过**自定义过滤器**在唤醒检查阶段判断消息是否命中任意规则的关键词：
   - 未命中 → 插件不唤醒、不参与，机器人按原有 @ 唤醒 / LLM 流程工作；
   - 命中 → 插件唤醒并处理该消息。
2. 命中后按规则配置顺序解析每条回复：普通文字行组装为 `Plain` 组件、行首 `[图片]` 标记行组装为 `Image` 组件（图片池引用在编译期解析为插件数据目录下的绝对路径；URL 用 `Image.fromURL`、本地路径用 `Image.fromFileSystem`），再逐条通过 `event.send()` 发出；
3. 至少成功发出一条后调用 `event.stop_event()` 阻断事件传播，避免 LLM 重复回复。

## 已验证环境

- AstrBot v4.14.6（pip 发布版）
- 平台适配器：aiocqhttp（OneBot v11，含 napcatQQ）
- Python 3.11

**版本要求**：AstrBot ≥ v4.10.4（依赖 WebUI 的 `template_list` 配置类型；旧版加载时会在日志中明确报"不受支持的配置类型"）。`author` 为 astrbot 必填元数据字段，如需修改请编辑 `metadata.yaml`。

## 已知限制

- 多条回复用单独一行 `---` 分隔，若回复正文某行恰好等于 `---` 会被误认为分隔符（可修改 `main.py` 顶部的 `REPLY_SEPARATOR` 常量）；
- 行首恰好以 `[图片]` / `[img]` 开头的普通文字会被当作图片标记；如需发送这类纯文字，可改用全角括号（`［图片］`）等写法避开；
- 图片格式方面插件与适配器均不做校验（发送时以 base64 原样透传），jpg / png / **gif（动图正常播放）** / webp / bmp 均可；QQ 对超大图片可能压缩或拒收，建议单图控制在 10MB 以内；
- WebUI 图片上传依赖较新版本的 AstrBot（配置 schema 的 `file` 类型）；旧版本中该字段会退化显示为普通文本框，此时可手动填写图片 URL / 绝对路径；
- 图片池按上传目录共享，所有规则的图片池文件存放在同一目录，删除图片请到插件数据目录 `files/rules.keyword_reply.images/` 下操作；
- 「`[图片:编号]`」按图片池中**有效文件**的顺序编号；删除某个文件后，后面文件的编号会依次前移，请同步调整回复内容中的引用（按文件名引用不受影响）；
- **安全边界**：插件对配置内容完全信任——能编辑插件配置的人可让机器人发送服务器上任意可读文件作为图片，或让 AstrBot 进程下载任意 URL（含内网地址）。请勿把 WebUI 的插件配置权限开放给不信任的账号；
- 图片仅支持 URL 与本地文件路径两种来源（本地路径需 AstrBot 进程可访问，Docker 部署时注意挂载目录）；不支持 base64 与 @ 等其他富文本组件；
- 某条消息发送失败（如图片地址无效）时会记录日志并跳过，继续发送后续消息；
- 同一条消息命中多条规则时，会按规则顺序把所有命中规则的回复**全部**发出；
- 规则的关键词或回复内容为空时，该规则自动失效（不会触发、不报错）。
